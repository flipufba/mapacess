# Ambiente computacional

Ambiente utilizado na etapa de extração e processamento dos dados do projeto MapAcess.

| Ferramenta | Versão | Finalidade |
|---|---|---|
| QGIS | 3.44.3 | Visualização, inspeção, análise espacial e produção cartográfica |
| Python | 3.12.3 | Automação da extração e análise dos dados |
| requests | 2.31.0 | Requisições HTTP à ohsome API |
| Visual Studio Code | 1.134.0 | Desenvolvimento e edição dos scripts |
| ohsome API | v1 | Recuperação histórica dos dados do OpenStreetMap |

As dependências Python necessárias para execução dos scripts estão registradas no arquivo `requirements.txt`.
